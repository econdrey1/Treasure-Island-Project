Treasure Island is a beginner Python text based adventure game that I created to practice using conditional statements and user input. The goal of the game is to make the correct choices and find the hidden treasure.
Throughout the game, the player has to choose which direction to go, decide whether to wait for a boat or swim across a lake, and choose between different colored doors. Each decision leads to a different outcome. Some choices lead to a “Game Over,” while one path leads to finding the treasure and winning the game.
What I Learned
While building this project, I practiced using:
- print() statements
- input() statements
- if, elif, and else
- Nested conditional statements
- Strings
- The .lower() method
- Indentation
- Basic game logic
How to Play
Run the Python file and follow the instructions shown in the terminal. Type the requested choices, such as left, wait, or a door color. The goal is to make the right decisions and reach the treasure.
Purpose
I created this project to improve my understanding of Python decision-making and to learn how user input can control different paths in a program.
